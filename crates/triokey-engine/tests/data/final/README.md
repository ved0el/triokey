# Blind line sets

Five sets in the same five registers as `../mixed/` (see its README), written for this project
by people who never saw the engine or its failures. One line is one message, spelled exactly as its author
wants it to appear on screen, in the same file format as `../mixed/`.

They are the blind test of the typing benchmark (`tests/realtext.rs`, `REALTEXT_SETS=final`):
always run whole, never split, never dumped. When running them, read only the totals in the
table; never read their failures, and never change the engine or its data because of a line
seen here. A set whose failures have been read is no longer blind and has to be replaced.

All names in the lines are invented. These files are MIT licensed like the rest of the
repository.
