# TrioKey Implementation Plan (M1 → M3 lõi, M2 tới mức "build + unit test")

> Tên tạm lúc viết kế hoạch này là EVJ; tên, đường dẫn crate và lệnh dưới đây đã đổi sang TrioKey.

**Goal:** Bộ gõ Telex cá nhân cho Windows: tự giữ từ tiếng Anh, tự nhường IME CJK (Chinese, Japanese, Korean) đang bật (tiếng Nhật gõ thử tay, Trung/Hàn mới có unit test), không đổi gì trong danh sách bàn phím của Windows.

**Architecture:** Cargo workspace hai crate. `triokey-engine`: thư viện Rust thuần, nhận phím, trả về `Outcome` (cho qua / thay bằng xoá N + chèn S); kiểm hết bằng `cargo test`. `triokey`: exe Windows dùng `windows-sys`, keyboard hook `WH_KEYBOARD_LL` + `SendInput`, đọc trạng thái IME bằng `ImmGetDefaultIMEWnd` + `WM_IME_CONTROL`.

**Tech Stack:** Rust stable 1.100 (host `x86_64-pc-windows-gnu`, qua mise, `mise.toml` ở gốc), crate `vi = "0.8.0"` (MIT) cho biến đổi Telex nếu qua Task 1, `windows-sys = "0.59"`. Không thêm dependency khác nếu không có lý do ghi trong task.

**Spec:** `docs/superpowers/specs/2026-11-25-triokey-design.md` (đọc trước khi làm bất kỳ task nào).

## Global Constraints

- Không bao giờ chạy hook, `SendInput`, hay `triokey.exe` trên máy này. Chỉ `cargo build`, `cargo test`, `cargo clippy`. Lần chạy exe đầu tiên là điểm dừng cho người dùng.
- Không đăng ký TSF, không gọi `LoadKeyboardLayout`/`ActivateKeyboardLayout`/`InstallLayoutOrTip`, không ghi registry trong task nào của kế hoạch này.
- Không ghi phím ra đĩa. Mạng chỉ dùng để kiểm tra và tải bản cập nhật có chữ ký từ GitHub (thêm ở M5, spec 5.8; tắt được).
- Không chép mã nguồn, bảng dữ liệu hay file test từ VKey hoặc Vikey (GPL-3.0). Chỉ dùng hành vi được mô tả trong spec. `vi` (MIT) và VieLotus (MIT) được đọc/chuyển thể, có ghi nguồn trong `NOTICE.md`.
- Chữ xuất ra là Unicode dựng sẵn (NFC); `Edit::delete` đếm theo ký tự trên màn hình (mỗi chữ có dấu = 1).
- Bỏ dấu mặc định kiểu cũ (`hòa`, `thúy`); có `ToneStyle::New`.
- Không commit, không push. Sau mỗi task được duyệt, người điều phối `git add -A` (chỉ stage).
- Lệnh chạy từ gốc repo qua mise: `mise x -- cargo test --workspace`.

## Review Focus

1. Chữ hoa: `Vieejt` → `Việt`, `VIEEJT` → `VIỆT`, `DDuowngf` → `Đường`; trả lại phím giữ nguyên hoa/thường (`Windows`, `HTML`). → test trong Task 4.
2. Backspace giữa từ rồi gõ tiếp: sau `tieesng`, ⌫×2 hiện `tiế`; gõ `ng` → `tiếng` (phím gốc được suy lại từ chữ còn trên màn hình). → Task 4.
3. Từ rất dài hoặc dán chuỗi không phải chữ: 40 phím chữ liên tục không panic, không tràn, kết quả = phím gốc. → Task 4.
